# Origine et diffusion des ressources

Les contenus, le logo et les schémas sont issus du corpus EDEN School fourni pour cette demande. Les ressources ne sont pas présentées comme des œuvres sous licence libre. Conserver l’attribution EDEN et respecter les droits ainsi que les règles de diffusion de l’établissement.

Le code de cette adaptation est fourni pour l’usage et la modification du projet demandé. Aucune clé, aucun compte ni aucune donnée d’élève réelle ne figure dans le dépôt. Les fichiers de police du système de génération ne sont pas distribués.

Le site publié n’inclut pas les dossiers de corrigés du corpus professeur. Les contrôles formatifs programmés restent lisibles dans le code, comme dans toute application cliente sans serveur d’évaluation.
