Le lancement en classe

1. Diffuse l’adresse principale du site dans Eden Hub.

2. Les élèves saisissent un prénom ou un code, puis commencent le diagnostic.

3. Donne les départs à voix haute. Pause à 14h30, reprise à 14h45.

4. À 16h10, fais enregistrer le bilan HTML puis le remettre dans le dépôt.

Règle de lecture : une action, un test, une explication. Les aides et les schémas restent à la demande.

Relire une progression

Ouvre le JSON remis par l’élève. Il reste sur ton appareil. Les explications sont à apprécier par le professeur, sans note automatique.

Pas de fausse validation

Le parcours vérifie les ordres, les ressources et le résultat du code. Cocher ou avancer ne vaut pas une validation pédagogique.

Les comptes Eden Hub existants ne sont pas raccordés automatiquement. Le service optionnel ci-dessous collecte les essais du bonus ; les autres réponses restent dans les exports.
