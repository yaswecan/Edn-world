# Exemple fictif V6

`exemple_export_DEMO.zip` contient le dossier de « DEMO FONCTIONS ». Les quatre programmes passent les contrôles finaux : pré-correction **20/20, A2, à relire**. Sur doubler, le premier code affichait au lieu de renvoyer (2/7 contrôles). Le dernier code, après un indice, réussit 7/7.

Le fichier `exemple_correction_DEMO.xlsx` est la feuille individuelle extraite : Correction, Barème, Repères et Essais. L’onglet Essais compare premier et dernier code et indique l’aide. Il n’y a ni élève réel ni validation humaine prétendue. Les sources originales et la progression sont dans le ZIP.

Recréer cet exemple sans base : `node scripts/example-export.mjs`.
