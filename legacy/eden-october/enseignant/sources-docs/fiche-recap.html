À garder après la séance

Je déclare. J’appelle. Je réutilise.

function additionner(a, b) {
  return a + b;
}
const total = additionner(2, 3);
console.log(total);

a et b : paramètres. 2 et 3 : arguments. 5 : résultat renvoyé, puis stocké dans total.

Déclarer ne lance pas la fonction. Afficher ne remplace pas renvoyer.

À garder après la séance

Une condition. Des tests.

function peutEntrer(ticket, invite, ferme) {
  return (ticket || invite) && !ferme;
}

&& : les deux. || : au moins un. ! : inverse.

Prévois → teste → explique → corrige → reteste.

Teste aussi un refus et le seuil exact. Un seul exemple réussi ne suffit pas.
