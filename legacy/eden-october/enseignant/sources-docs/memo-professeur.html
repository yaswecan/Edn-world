Mémo professeur · réactiver

Une fonction : trois gestes.

Déclarer

J’écris ce que la fonction fera. Le paramètre est le nom de l’entrée.

Appeler

Je lance la fonction avec une valeur. Cette valeur est l’argument.

Renvoyer

return fournit une valeur au code qui a appelé. Une variable peut la garder.

Afficher

console.log rend une valeur visible dans la console. Il ne remplace pas return.

La question qui éclaire :

« Qu’est-ce qui entre ? Qu’est-ce qui sort ? Où gardes-tu le résultat ? »

Mémo professeur · le cours du jour

Deux règles. Une décision.

ET demande les deux conditions. OU en accepte au moins une, y compris les deux. NON inverse un booléen.

Fais passer de la phrase au test.

Dire la règle → regrouper → prévoir les cas → coder → vérifier.

Ne demande pas seulement un succès.

Pour un seuil de 14 : tester 13, 14 et 15. Pour deux booléens : les 4 combinaisons. Pour trois : les 8 combinaisons.

« Quel cas prouve que ta règle ne laisse pas entrer quelqu’un à tort ? »

Trois difficultés à isoler

La phrase mal comprise ; le mauvais opérateur ; le code qui ne renvoie pas de valeur. Ne les confonds pas dans ton retour à l’élève.

Deux distinctions indispensables

Non remis = NE sans note, pas zéro. Une copie remise vide peut ne montrer aucun indicateur.

Code non interprétable = à relire. Le mini-labo accepte le sous-ensemble travaillé ; une autre écriture peut être valable. Ne valide pas sans lire.
