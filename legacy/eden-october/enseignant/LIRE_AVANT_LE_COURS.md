# Ta séance en pratique

Ouvrir `/prof.html` : présentation, trame, mémo, suivi et exports sont réunis.

Avant : vérifier `/api/health`, faire une remise avec un profil fictif et ouvrir son Excel. Distribuer l’URL élève et le code de classe. Les élèves ne dézippent rien. Demander de garder leur clé privée de reprise.

Au départ : diagnostic fonctions **20 min** (3 + 4 + 5 + 6 + 2), seul. Quatre programmes à écrire ; console, aperçu et tests disponibles. Les contrôles guident sans donner le code solution. « Sauvegarder » enregistre du travail ; « Remettre le diagnostic » fige la copie.

Après : correction flash, six missions de logique, pause, exercices gradués, point de maîtrise, bilan. Le créneau du jeudi est configurable, 175 min proposées pause comprise. Le défi reste facultatif et peut être repris.

Pour récupérer : se connecter → ouvrir un élève → comparer premier essai et dernier code, consulter indices et tests → ajuster les 20 points avec commentaire → enregistrer la correction → télécharger le dossier. Pour tous les élèves : « Télécharger les dossiers élèves ». Vérifier les fichiers avant de quitter.

Un dossier comprend la progression du cours, les codes, la copie diagnostique figée, la pré-correction et la relecture, une feuille Excel à quatre onglets et un manifeste. Sans diagnostic remis, NE et pas de zéro.

Conservation par défaut : 30 jours. Ne pas publier les exports dans le dépôt GitHub. Mot de passe professeur privé. Un même nom n’ouvre pas automatiquement le même dossier.

Yacine

La note porte sur la copie remise après essais. Les premiers essais permettent de voir les difficultés initiales, mais leurs dates et l’aide consultée viennent du navigateur : ce ne sont pas des preuves d’autonomie. Un élève bloqué conserve son code et passe avec « À reprendre ». On remet à la fin des 20 minutes, même incomplet.
