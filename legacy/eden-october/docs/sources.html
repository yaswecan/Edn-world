Conception ajoutée

Les histoires de salle, concert et jeu, les six missions, le mini-labo encadré, les schémas et le bonus de circuits sont conçus pour cette application. Ils ne sont pas présentés comme des contenus déjà rédigés dans le classeur.

Les horaires exacts du jeudi ne figuraient pas dans les éléments accessibles. Les 175 minutes constituent une proposition, dont 15 minutes de pause. Le professeur règle le début dans son espace ou adapte les durées dans le contenu.

Diagnostic et grille adaptés

Le professeur demande une réactivation de 20 minutes sur les fonctions du cours précédent. Le modèle de grille CSS fourni est adapté à ces compétences : même structure par indicateurs, mêmes seuils globaux NA/EC/A1/A2, critères et pondérations JavaScript distincts. Aucun ancien nom ou résultat élève n’est repris. Trois exercices gradués et un défi de fonction réutilisent ensuite la logique.

Limites des modèles

Nous travaillons avec des booléens explicites. En JavaScript général, && et || ne renvoient pas toujours des booléens. La conversion truthy/falsy, les opérations bit à bit et le court-circuit avec effets de bord ne sont pas des objectifs de cette séance. Les schémas sont des modèles logiques, pas des plans électriques.

Le mini-labo évalue un sous-ensemble sûr : comparaisons, opérateurs logiques, parenthèses, if / else et deux console.log de messages fixes. Un second mini-interpréteur AST ajoute les fonctions, return, variables et calculs pour le diagnostic et les exercices progressifs. Il n’exécute pas du code arbitraire. Utiliser un véritable environnement JavaScript pour aller au-delà.
